# 设备适配与测试清单

本目录记录设备适配的说明和验证证据；协议与实现仍位于源码目录。
主 README 只保留此入口，不逐型号追加测试记录。

## 维护约定

- 每个型号使用 `<vendor>-<model>.md`；同型号不同固件分别记录验证范围。
- 参数路径、类型、枚举和回读规则属于 CWMP 合同；用户期望 SSID、VLAN
  等属于 provisioning 配置，不混入设备测试文档。
- 共用协议和发现逻辑不得加入型号判断；特殊行为放在厂商/型号模块。
- 文档不包含真实账号密码、动态维护凭据、完整客户配置或抓包载荷。
- “注册”“转发”“管理上线”“配置同步”“重启保持”分别验收。
  未执行的项目注明未验证，不因 O5、计数增长或参数存在就标记支持。
- 源码测试证明逻辑和输出；实机测试证明该设备/固件的实际行为，
  两者不能互相替代。回退后的现场状态与历史成功证据分开记录。

## 新增记录模板

每份记录至少包含以下内容：

1. **身份与范围**：厂商、型号、硬件/固件版本、精确匹配条件、实现位置。
2. **配置说明**：自动下发内容、本机前置条件、保护的既有配置、
   不支持的能力及必要的变更授权。
3. **源码测试**：命令、feature 组合、结果、对应代码版本。
4. **实机测试清单**：

| 项目 | 验收条件 | 结果与证据 |
| --- | --- | --- |
| 身份匹配 | 正确型号命中；相似/未知型号不误匹配 | 未验证 |
| 光侧注册 | O5 稳定；重新注册后可恢复 | 未验证 |
| OMCI 配置 | 写入回读一致；自定义配置不被覆盖 | 未验证 |
| LAN 转发 | 双向 ARP、小包及大包，记录数量和丢包率 | 未验证 |
| 管理通道 | 地址获取、ACS 可达、真实 CWMP Inform 与身份关联 | 未验证 |
| 参数发现 | 对象实例、类型、可写性、冲突处理 | 未验证 |
| 配置同步 | 目标字段写入并回读；未涉及业务保持 | 未验证 |
| 持久与恢复 | 重启/重新注册后核对；配置漂移可恢复 | 未验证 |
| 失败与回退 | 拒绝/超时明确报错；备份和回退验证 | 未验证 |
| feature 开关 | 启用与关闭路径均测试 | 未验证 |

5. **结论与现场状态**：按能力列出已验证、条件性支持、未验证、
   不支持；注明是否已经回退。更新记录时关联测试所用提交版本。
